Ship with caveats

  • The test set is too small to rule out a drop in correctness of the size that matters; more test questions would make the conclusion firm.
  • Scores for correctness vary too much between identical runs to judge small differences.

How to read this

Both configurations answered the same questions
Every comparison is made question by question, so differences in question difficulty cancel out. Each question was answered 3 times by each configuration and the results averaged.
“No real change”
We measured how much the current configuration's own scores move between identical runs. A difference smaller than that run-to-run variation is not a real change and is never counted as a regression.
“No meaningful drop”
The goal of an upgrade is usually to be no worse on quality while being cheaper or faster, not to be strictly better. For the main measure, a drop is meaningful when it could exceed 5.0 points on a 0–100 scale.
What this does not cover
The results describe this test set and these measures. They are strong evidence, not a guarantee about every future question, which is why we keep monitoring after a switch.
